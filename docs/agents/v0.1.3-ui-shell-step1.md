# Codex Task: v0.1.3 UI/UX Overhaul — Step 1 (App Shell Refactor)

## Summary
We are beginning the UI/UX refresh for **Creator Toolkit** for release **v0.1.3**. This first step should focus ONLY on the layout shell — introducing the 3-panel layout (sidebar → main workspace → right “Imagine” inspector) while keeping existing dashboard behavior intact. The change must be **modular**, **revertable**, and **test-friendly**.

This will be committed to a new branch (example):  
`feature/ui-shell-v0.1.3`

---

## Objectives
1. Add a **collapsible left sidebar** for navigation (Create, Library, Publish, Jobs, System).
2. Add a **persistent, collapsible right inspector** for Imagine (prompt tools, AI outputs).
3. Move existing dashboard content into a **center workspace** that resizes when panels are collapsed.
4. Do **not** change backend/API behavior in this step.
5. Keep the code structured so later steps (Library view, Storyboard, Video Editor) can plug in.

---

## Constraints
- Must not break current dashboard routes or data fetching.
- Must not change FastAPI route signatures.
- Must keep current tests passing (`pytest`).
- Must keep CI linters happy (`ruff check .` and `black --check .`).
- All new UI logic must be confined to the frontend (likely `static/app.js` or equivalent).

---

## Files to Touch (expected)
- `static/app.js` (or current main JS entry)
- `templates/index.html` (only if needed to add container divs)
- `static/css/...` (single CSS block or file to support the new layout)

**Do NOT edit**:
- `main.py` business endpoints
- `modules/*.py`
- `tests/*.py`

## Step-by-Step Tasks

### 1. Create a Shell Renderer
**Goal:** Centralize layout markup so the app always renders inside a 3-column shell.

**Action (example):**
```js
function renderShell() {
  const root = document.getElementById("app");
  root.innerHTML = `
    <div id="ct-shell" class="ct-shell">
      <aside id="ct-sidebar" class="ct-sidebar ct-sidebar--open"></aside>
      <main id="ct-main" class="ct-main"></main>
      <aside id="ct-inspector" class="ct-inspector ct-inspector--open"></aside>
    </div>
  `;

  renderSidebar();
  renderMainWorkspace();
  renderInspector();
}
```

**Why:** future views (Library, Storyboard, etc.) will mount into `#ct-main` without changing the shell.

### 3. Inspector (Right)
**Goal:** Add the persistent Imagine panel as a UI container — behavior can be fleshed out in later steps.

**Action:**
- Render header: “IMAGINE”
- Add 2–3 placeholder cards (e.g. “Music created and added to assets”, “Scene created and added to assets”, “What would you like to do?”)
- Add a bottom action: “Create a new video”
- Add a collapse button on the outside edge (arrow to the right)

**Behavior:**
- Toggle class: `ct-inspector--open` / `ct-inspector--closed`
- Use CSS transform to slide in/out:
  ```css
  .ct-inspector {
    transition: transform 0.25s ease;
  }
  .ct-inspector--closed {
    transform: translateX(100%);
  }
  ```
